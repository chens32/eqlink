# EqLink 虚拟机验收清单

在一台专用 Linux VM 和至少两台 Windows 10/11 x64 VM 上执行。测试 ping 与入站 TCP/UDP 前，为虚拟网段添加范围受限的 Windows Defender 防火墙规则；不要关闭整机防火墙。记录系统版本、组件版本、服务器设置、测试时间及抓包文件；密钥和导入包不得放进报告。

| 场景 | 操作 | 通过条件 |
| --- | --- | --- |
| 地址与互访 | 为 A、B 分别导入并连接；重启客户端和服务端 | A、B 获得各自固定虚拟 IP；能互 ping、双向建立 TCP 连接并收发 UDP 数据；重启后地址不变 |
| UDP 优先 | 两条外层均可达，自动模式连接 | GUI 显示 UDP；服务端每台设备只有一条 OpenVPN 会话 |
| UDP 故障 | 阻断外层 UDP 或终止 Hysteria 客户端进程 | 自动模式在稳定网络中 60 秒内恢复虚拟网通信并显示 TCP；仅 UDP 模式保持断开 |
| TCP 故障 | 阻断外层 TCP 或终止 Xray 客户端进程 | 仅 TCP 模式断开；自动模式在 UDP 可用时使用 UDP |
| 双路径故障 | 同时阻断外层 UDP/TCP | GUI 明确显示断开；OpenVPN 不直连服务端公网地址 |
| UDP 恢复 | 先转到 TCP，再恢复 UDP | 稳定的 TCP 虚拟会话不被主动打断；下次重连优先 UDP |
| 吊销 | 吊销 A，观察 A、B | A 的旧会话断开且无法重新认证；B 仍可连接。若管理接口故障导致 OpenVPN 重启，记录 B 的中断 |
| 认证与导入 | 错误包密码、篡改包、过期证书、错误外层凭据 | 导入或连接失败并显示可操作信息，不发生无限快速切换 |
| 网段冲突 | Windows VM 接入与虚拟 `/24` 重叠的网络 | 客户端拒绝连接并提示更换网段 |
| 出口约束 | 经两条外层访问指定端口，再访问其他 loopback、公网、IPv6 地址/端口 | 仅指定两个 TCP 端口可访问，其余全部拒绝 |
| 无内层直连 | 物理网卡抓包覆盖启动、切换及双路径故障 | 未见到直接连服务器公网的 OpenVPN TCP 或明文 OpenVPN 流量 |
| 安装/升级/卸载 | 安装、升级、卸载 EqLink | EqLink 服务与 GUI 正常；机器上原有的 OpenVPN 安装及其他配置保留 |

抓包只能证明测试窗口内没有内层 OpenVPN 直连泄露，不能保证外层流量无法识别或封锁。60 秒指标应以虚拟网络重新可通信的时间计算，不能用外层代理端口启动或 GUI 状态代替。未达标时保存 OpenVPN 与两条外层日志、阻断/恢复时间线，再调整超时参数。
