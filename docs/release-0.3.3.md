# EqLink Windows 客户端 0.3.3 测试版

新增按网络独立保存的域名覆写，兼容现有 0.3.0/v2 服务端及已登记身份，保留 0.3.2 的物理出口与 UDP 恢复修复。服务端、通用包、CA、REALITY 密钥和设备地址无需变更。

## 使用与安装

- 安装 `EqLink-Setup-0.3.3.exe` 可使用单文件安装器安装客户端及需要的官方 OpenVPN；已安装受支持 OpenVPN 时也可用 `EqLink-0.3.3.msi`。
- 已登记用户直接升级，身份、地址、模式和出口设置保留。升级会短暂中断 EqLink；升级后手动连接，Meta 可保持运行。
- 打开“域名覆写”，勾选启用，输入 `172.21.10.2 rancher.armhpc.home.arpa` 等条目，保存并按需通过 UAC。保存无需断开 VPN。
- 配置按网络保存于 `%ProgramData%\EqLink\hosts\<networkIdN>.json`；后台服务只维护系统 hosts 的 EqLink 专属区块，冲突时拒绝覆盖其他条目。
- 默认关闭，测试映射会在验证后清理。完整说明见源码中的 `docs/hosts-overrides.md`。

## 验证范围

覆盖解析及网段限制、独立保存、版本冲突、网络切换、编码和原始字节保留、冲突拒绝、停用清理、GUI 控件及系统解析。真实系统解析测试在 Meta 持续运行时将同一测试域名从 `.2` 更新到 `.3`，清理后核对系统 hosts 原始 SHA-256。

系统解析以受管 hosts 区块提供；应用使用自己的 DNS/DoH/显式代理时不保证遵循映射。HTTPS 证书仍需匹配域名并受信任。手动断开 VPN 保留映射，WFP 继续控制虚拟网段；正常服务退出清理区块，重启重新应用启用设置。

本机已从 0.3.2 升级到 0.3.3，安装前后身份、模式、出口及其他 OpenVPN 配置保持；Meta 进程保持。已安装服务的 12 项功能检查全部通过，包括通过域名 ping VPN 服务端、连接中更新且组件 PID 保持、服务停止清理及重启加载。测试结束恢复关闭/零条目，系统 hosts 原始字节哈希完全一致，最终虚拟 IP `.11` 通过 HY2 连接。

首轮服务重启时的文件写入失败样本及先行 DNS/NRPT 实验失败样本均保留。最终方案为专属 hosts 区块；加入针对 Windows 文件共享冲突的最多 10 秒有限重试，临时文件锁回归及真实服务重启复测通过。未取得其他软件持有文件的证据，不将该问题归因于 Meta。

详细执行状态见 `ACCEPTANCE.json`，`passed / failed / skipped / unavailable` 保留各自含义。本版不把前轮回退测试或本机测试扩大为完整双客户端及 Windows 生命周期验收，CI 继续停用；项目安装器尚未做项目代码签名。

## 回滚

先在 GUI 停用域名覆写并断开连接，备份管理员/SYSTEM 专用的 `%ProgramData%\EqLink`。使用正常卸载流程清理自有 hosts 区块和 WFP 规则，再安装保留的 0.3.2。旧版忽略独立 hosts 配置，不将其转入通用包。不要手动删除程序目录来代替卸载。
