# EqLink Windows 客户端 0.3.2 测试版

本版修复指定物理出口时，HY2 冷启动和 UDP 恢复可能永久失效的问题。兼容现有 0.3.0/v2 服务端及已导入的通用包；升级保留本机设备身份、地址与出口设置。服务端 CA、REALITY 密钥、授权、虚拟网段和 Rancher 网关继续沿用。

## 故障与修复

- 使用实际 `PhysicalEgress` 类复现：旧 HY2 本地 UDP 端口关闭后，迟到报文触发 Windows `ConnectionReset / 10054`，旧代码的主接收任务进入 `Faulted`，新进程的数据也无法转发。复现只使用本机物理 IPv4，不依赖公网。
- 主接收循环继续处理 UDP 瞬态错误；上游发送或接收失败时清理对应套接字，下一份报文可创建新连接。
- 登记阶段结束、模式关闭 UDP、HY2 进程更换时清理旧 UDP 对应关系，保留稳定本地入口和指定物理网卡绑定。
- 诊断新增 `physicalEgressRelay`：后台任务状态、UDP 收发/错误计数和最近套接字错误码；不保存报文正文、私钥或凭据。计数也可能包含清理旧套接字时产生的取消错误，不能直接用作公网丢包率。
- 后台发现指定出口转发任务意外停止时，撤销虚拟网段放行并重建连接，报告 `EGRESS_RELAY_FAILED`。

Windows UDP 可以将前次发送引起的 ICMP Port Unreachable 报告为 WSAECONNRESET，参见 [Microsoft recv 文档](https://learn.microsoft.com/en-us/windows/win32/api/winsock2/nf-winsock2-recv)。本版结论基于实际类复现和本机实网验证，不保证所有网络环境的 UDP 都可用。

## 安装与回滚

- `EqLink-Setup-0.3.2.exe`：单文件 Burn 安装包，包含客户端 MSI 和固定版本、哈希及官方签名校验的 OpenVPN MSI。
- `EqLink-0.3.2.msi`：独立客户端 MSI，适用于已安装受支持 OpenVPN 的机器。
- 已登记的 0.3.1 用户直接升级，无需重新导入 `.eqlink`、重新登记或重新分配虚拟地址。连接会在升级期间中断，升级后手动连接。
- 安装器保留独立 OpenVPN 安装及其他配置。项目安装器尚未做项目代码签名。
- 需要回滚时，先断开 EqLink，保留受限权限的 `C:\ProgramData\EqLink` 持久身份和设置备份。卸载 0.3.2 后安装已保存的 0.3.1；正常卸载通过 EqLink 自有规则清理入口执行，不能手工删除程序目录或清空系统防火墙。
- 本机测试已保存 0.3.1 原安装包及管理员/SYSTEM 可读的加密身份备份；该私密目录不进入发行包或 Git。完整卸载/失败回滚/重启验收继续作为单独门槛。

## 验证范围

实际类回归覆盖旧端口迟到报文、连续进程端口替换、上游端口关闭恢复、显式套接字清理与后台任务故障检测。真实网络测试使用本机指定物理出口，Meta 持续运行；详细结果和测量口径见随包 `ACCEPTANCE.json`。

用户本轮明确要求仅在本机验证，因此另一客户端主动发起及双向随机载荷 TCP/UDP 复测保持 `skipped`；前一轮两台客户端的历史结果不作为本版完整验收通过的依据。完整生命周期和其他未执行门槛仍保留，CI 继续停用。

### 2026-10-19 本机实网结果

| 场景 | 结果 | 最大用时 |
|---|---|---:|
| 全新 Auto 直接建立 HY2 | 5/5 | 25.94 秒 |
| HY2 进程退出后恢复 TCP | 5/5 | 12.23 秒 |
| Xray 进程退出后恢复 HY2 | 5/5 | 5.74 秒 |
| 持续 UDP 丢包后恢复 TCP | 5/5 | 34.83 秒 |
| 移除丢包规则后 UDP 恢复 | 5/5 | 5.48 秒 |
| UDP 恢复后继续保持健康 TCP，观察 10 秒 | 5/5 | — |

恢复计时要求服务端虚拟 IP 的认证 TLS 通信成功、Connected 与 WFP 放行同时成立。全部达到 60 秒硬门槛；持续 UDP 丢包场景未全部达到 30 秒优化目标。当前环境没有显示持续 UDP 封锁，但不排除临时丢包或其他网络的 UDP 限制。

本机到现有另一客户端 `.10` 的 ping 10/10、TCP SSH banner 检查通过。三个抓包窗口 EventsLost=0，限定物理/Meta 组件与窗口内未观察到虚拟网段或直连公网内层端口出站。

Windows 防火墙规则注入因 Private 配置关闭而无效，保留为 `unavailable`；替代的动态 WFP 丢弃会话独立于该配置，每次均先确认认证 UDP 失败、TCP 仍可用，并核对关闭会话后过滤器已不存在。先行进程暂停测试的原始失败保留：进程被客户端重建后故障不再持续，该样本不等同于持续 UDP 阻断。
