# EqLink v1.0.0 发布草稿

本次将 Windows 客户端与 Linux 服务端统一为 1.0.0，作为首个拟正式版本创建 PR 和 GitHub draft release。**发布仍为草稿，完整验收未完成。**

包含通用 v2 入网包、独立设备身份、自动/静态地址申请、HY2 优先与 REALITY 回退、指定物理出口、WFP 网段保护、连接/速率统计及独立域名覆写。保持现有 v2 协议与身份兼容，不重新生成既有 CA 或 REALITY 密钥。

本次源码审查修复控制接口读取完整响应后才检查大小的问题，改为流式限制；拒绝未定义的地址模式；统一组件版本并更新 MSI ProductCode；补充许可、公开仓库维护文件和 CI。详见 [英文发布说明](release-1.0.0.md)。

历史两地测试继续按原版本保留。本次构建与测试以发行包 `ACCEPTANCE.json` 为准；两台当前版本客户端、完整 Windows 生命周期、地址/吊销、BFE/网卡/DNS 矩阵、原生 k3s 恢复回滚和长期稳定性仍需补验。Windows 安装器签名与第三方完整对应源码分发义务也属于公开发布前的门槛。

EqLink 原创源码按用户指定使用 GPL-3.0-only；OpenVPN 的 GPLv2、Xray 的 MPL-2.0、MIT 和其他组件许可继续分别适用，不能统一改标为 GPLv3。具体核对见 [许可审查](licensing.md)。
